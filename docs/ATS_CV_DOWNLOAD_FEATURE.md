### User Flow

```
User on Results Page
    ↓
Sees "Download Your Updates" section
    ↓
Can choose:
├─ Download Summary (quick actionable list)
└─ Download Updated CV (full CV with recommendations)
    ↓
Click button
    ↓

    ↓
Downloaded to device
    ↓
User can update CV manually with suggestions
```

### Backend Process

#### Step 1: Collect Data
```typescript
{
  originalCV: string           // User's original CV text
  missingKeywords: string[]    // Keywords not in CV
  recommendations: Array       // Suggested improvements
  matchScore: number          // 0-100%
  atsScore: number            // 0-100%
  keywordMatchPercentage: number  // 0-100%
}
```

#### Step 2: Generate Content
```
For Updated CV:
1. Add header with analysis scores
2. List missing keywords
3. Organize recommendations by priority
4. Include original CV content
5. Add implementation tips
6. Format with proper sections

For Summary:
1. Add score overview
2. List key findings
3. Show missing keywords (top 10)
4. Provide action plan
5. Keep concise and actionable
```

#### Step 3: Create Download
```typescript
const content = await generateUpdatedCV(data)
const blob = new Blob([content], { type: "text/plain" })
const url = window.URL.createObjectURL(blob)
const link = document.createElement("a")
link.href = url
link.download = `CV_Optimized_${date}.txt`
link.click()
```

## Code Example

### How Download Works (Simplified)

```typescript
// User clicks "Download Updated CV"
const handleDownloadUpdatedCV = async () => {
  // 1. Prepare data
  const data = {
    originalCV: cvText,
    missingKeywords: results.missingKeywords,
    recommendations: results.recommendations,
    matchScore: results.matchScore,
    atsScore: results.atsScore,
    keywordMatchPercentage: results.keywordMatchPercentage
  }

  // 2. Call server action to generate content
  const updatedContent = await generateUpdatedCV(data)

  // 3. Create download
  const blob = new Blob([updatedContent], { type: "text/plain" })
  const url = window.URL.createObjectURL(blob)
  const link = document.createElement("a")
  
  // 4. Trigger download
  link.href = url
  link.download = `CV_Optimized_${new Date().toISOString().split('T')[0]}.txt`
  link.click()
  
  // 5. Cleanup
  window.URL.revokeObjectURL(url)
}
```
