# Tech Stack

Expert analysis of the BidJobs platform technology stack.

## Core Framework
- **Next.js 16.2.1**: Utilizing App Router, Route Groups, and Server Actions.
- **React 19.2.4**: Leveraging the latest React features and optimizations.
- **TypeScript 5**: Ensuring type safety across the entire application.

## Frontend & UI
- **Tailwind CSS 4**: Modern CSS-first utility framework for styling.
- **Framer Motion 12.38.0**: Advanced animations and micro-interactions.
- **Lucide React 1.7.0**: Vector icons for UI elements.
- **Material Symbols**: Integrated via class names for specific iconography.
- **Dynamic Theming**: Premium dark mode/glassmorphism aesthetic.

## Backend & Data
- **Supabase**: Primary database (PostgreSQL) and Authentication.
- **@supabase/ssr**: Proper session handling and server-side rendering support.
- **@supabase/supabase-js**: Client-side interaction with Supabase services.

## Performance & Optimization
- **@vercel/analytics**: Real-time traffic and performance monitoring.
- **Babel Plugin React Compiler**: Automated React rendering optimizations.

## Tooling
- **ESLint 9**: Code quality and linting.
- **PostCSS**: CSS processing.
- **Zod**: Runtime schema validation.
- **React Hook Form**: Form state management and validation.
