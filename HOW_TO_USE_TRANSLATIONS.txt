STEP 1: EXPAND TRANSLATION FILES
════════════════════════════════════════════════════════════════════════════════

Open: locales/en.json

Add all your UI text like this:

  {
    "header": {
      "home": "Home",
      "about": "About",
      "jobs": "Browse Jobs"
    },
    "buttons": {
      "signIn": "Sign In",
      "signUp": "Sign Up",
      "save": "Save Changes"
    },
    "home": {
      "welcome": "Welcome to BidJobs",
      "subtitle": "Where elite talent meets opportunity"
    }
  }

Then open: locales/ar.json

Add Arabic translations with THE SAME KEYS:

  {
    "header": {
      "home": "الصفحة الرئيسية",
      "about": "من نحن",
      "jobs": "تصفح الوظائف"
    },
    "buttons": {
      "signIn": "تسجيل الدخول",
      "signUp": "إنشاء حساب",
      "save": "حفظ التغييرات"
    },
    "home": {
      "welcome": "مرحبا بك في BidJobs",
      "subtitle": "حيث يلتقي الموهوبون بالفرص"
    }
  }

⚠️  IMPORTANT: Keys MUST be identical in both files!

═══════════════════════════════════════════════════════════════════════════════

STEP 2: UPDATE YOUR COMPONENTS
════════════════════════════════════════════════════════════════════════════════

Template for ANY component with text:

  'use client';                                          ← Add this line
  
  import { useLanguage } from '@/app/providers/LanguageProvider';  ← Add this
  
  export function MyComponent() {
    const { t, locale, dir } = useLanguage();           ← Add this
    
    return (
      <div dir={dir}>                                   ← Add dir attribute
        <h1>{t('home.welcome')}</h1>                    ← Use t('key')
        <p>{t('home.subtitle')}</p>                     ← Use t('key')
        <button>{t('buttons.signIn')}</button>          ← Use t('key')
      </div>
    );
  }

That's the pattern. Use it everywhere!

WHAT THE HOOK RETURNS
════════════════════════════════════════════════════════════════════════════════

const { t, locale, dir } = useLanguage();

t        → Function to get translations
           t('header.home') → "Home" or "الصفحة الرئيسية"

locale   → Current language: 'en' or 'ar'
           if (locale === 'ar') { /* do something */ }

dir      → Text direction: 'ltr' or 'rtl'
           <div dir={dir}>...</div>

COMMON MISTAKES
════════════════════════════════════════════════════════════════════════════════

❌ WRONG: Hard-coded English only
  export function Button() {
    return <button>Sign In</button>;
  }

✅ RIGHT: Using translations
  'use client';
  import { useLanguage } from '@/app/providers/LanguageProvider';
  
  export function Button() {
    const { t } = useLanguage();
    return <button>{t('buttons.signIn')}</button>;
  }

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ WRONG: Forgot 'use client'
  import { useLanguage } from '@/app/providers/LanguageProvider';
  
  export function Page() {
    const { t } = useLanguage();  ← ERROR: Hook in server component!
    return <div>{t('key')}</div>;
  }

✅ RIGHT: Add 'use client'
  'use client';
  import { useLanguage } from '@/app/providers/LanguageProvider';
  
  export function Page() {
    const { t } = useLanguage();  ← Works!
    return <div>{t('key')}</div>;
  }

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ WRONG: Missing key in translations
  t('buttons.submit')  ← Key doesn't exist in JSON files
  Returns: "buttons.submit" (shows the key itself!)

✅ RIGHT: Key exists in both files
  // locales/en.json
  { "buttons": { "submit": "Submit" } }
  
  // locales/ar.json
  { "buttons": { "submit": "إرسال" } }
  
  t('buttons.submit')  ← Returns "Submit" or "إرسال"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ WRONG: Forgot dir attribute on root
  <div>
    <h1>{t('title')}</h1>
  </div>
  RTL layout breaks!

✅ RIGHT: Add dir attribute
  <div dir={dir}>
    <h1>{t('title')}</h1>
  </div>
  RTL layout works!

RTL LAYOUT TIPS
════════════════════════════════════════════════════════════════════════════════

Use Tailwind's RTL prefix:

  <div className="ml-4 rtl:mr-4 rtl:ml-0">
    Item aligned right in LTR, left in RTL
  </div>

Or add to global CSS:

  html[dir="rtl"] {
    direction: rtl;
    text-align: right;
  }

TRANSLATION KEY NAMING
════════════════════════════════════════════════════════════════════════════════

Use this naming pattern:

  namespace.section.item

Examples:
  header.nav.home
  buttons.primary.signIn
  form.labels.email
  form.placeholders.email
  messages.error.required
  messages.success.saved
